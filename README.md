# Peaceful Flight KMP

Peaceful Flight is a Kotlin Multiplatform rewrite of the original Android app for people who feel anxious about flying. The app is built to help during the whole flight journey: before takeoff, during cruise, in turbulence, and while landing.

Instead of being just a collection of generic calming tips, the app focuses on practical in-flight support. It combines education about normal flight sensations with short intervention tools that can be used when anxiety rises in real time.

The main features include a cockpit dashboard for each phase of the flight, a learn section with answers to common fear-of-flying questions, and a tools section with guided exercises such as Riding the Wave, Postpone the Worry, Worry Olympics, Reality Check, and Catastrophic Thinking. The app also includes live weather lookup, a G-force monitor based on phone sensors, SOS support screens, and text-to-speech guided content.

This repository contains the Kotlin Multiplatform version of the app, with shared business logic and UI for Android and iOS.
